Живой smoke выявил лишний вопрос для конкретного «Как выбрать УСН для своего ИП».
Причина: модель получает только общие признаки и могла повторно уточнять уже
достаточный локальный контекст. Исправлено: при context_sufficient=true уточнение
не вызывается, assistant_status=not_needed, question=null. Для недостаточного
контекста решение и текст вопроса остаются у LLM. Выбранная цель также не уточняется
повторно. Один формат или стадия без цели не блокируют вопрос. Это локальная
эвристика, не универсальный классификатор.

Регрессии усилены: конкретный запрос и выбранная цель не обращаются к clarify;
сквозной mocked transport отправляет один запрос вместо двух. Добавлена регрессия
для одного формата без цели. Независимое ревью обнаружило ложный not_needed у
«как выбрать»/«Помоги выбрать курс для бизнеса»: глагол совпадал с заголовком,
но объект не был задан. Gate сужен до распознанной бизнес-темы с содержательной
задачей; добавлена регрессия общего действия даже при semantic cosine=.8.
