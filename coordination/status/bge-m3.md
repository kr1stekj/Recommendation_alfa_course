# BGE-M3 и переносимый CPU-запуск — 15 ноября 2026

Задача: заменить ruBERT одной из предложенных моделей, проверить настоящий backup;
учесть уточнение владельца о последующей проверке на Windows. Ветка
`feat/cloud-llm-api`, база `2a02e8e81e726108fb126301575a17b8922780b0`.
Изменения локальные, не закоммичены, не опубликованы и не слиты. Старые документы
DEVELOPMENT.md, PLAN.md, PROTOCOL.md, status/codex.md сохранены без сброса.

## Реализовано

- BAAI/bge-m3, закреплённая revision 5617a9f61b028005a4858fdac845db406aefb181,
  CLS/L2, 1024 координаты, max_length=512, batch=4. Только dense; без reranker.
- CPU по умолчанию в build/runtime/Compose. MPS — явная необязательная настройка.
  Устройство не входит в encoder.json: индекс MPS можно открыть на CPU.
- Legacy ruBERT поддержан отдельно; несовместимые модель/длина отклоняются startup.
  Сборка атомарно публикует новое поколение; старое не удаляется.
- Официальный checkpoint загружается weights_only, trust_remote_code=false;
  accelerate уменьшает дублирование памяти. Чужие Docker-образы не использованы.
- Compose хранит модели и индекс в named volumes Linux, не на NTFS bind mount.
  Данные backup читаются из data/. Добавлена PowerShell-инструкция, окно health
  start_period=60m для долгого первого скачивания/сборки.
- /health показывает модель, revision, устройство, размерность и длину входа.
  scripts/benchmark_embeddings.py сохраняет условия, метрики и хэши проекций.

Контракты: specs/bge-m3.md, encoder.json, build CLI, переменные окружения, /health.
Схема исходных таблиц PostgreSQL не меняется. Новый fingerprint требует нового dataset;
история импортируется из backup, старые гостевые агрегаты не переносятся.

## Проверено

Настоящий backup: 1126×1024 конечных нормализованных векторов, 1115 доступных карточек,
10032 строки истории для 7339 пользователей. SHA256 официальных весов совпал;
файл 2271145830 байт. Build на MPS занял 2541.299 с без скачивания модели.
CPU/MPS cosine у двух контрольных запросов — 1.0. Это не полный тест всех входов.

Сравнение на том же каталоге/истории, проверены равные хэши исходных проекций:
гибрид ruBERT NDCG@5=0.4651, BGE=0.5458. Только пять старых seed-сценариев,
неполная разметка автора, не независимый контроль. BGE CPU short query p50=111.42 мс,
p95=2010.30 мс, 15 замеров, 10–17 токенов. Подробности: docs/embedding-comparison.md.

Полный unittest-прогон: 88 тестов без пропусков на отдельной PostgreSQL alfa_test;
дополнительный прогон пяти embeddings-тестов после уточнения проверки MPS→CPU прошёл.
HF_HUB_OFFLINE=1 python scripts/smoke_api.py с реальным BGE/CPU прошёл: starter,
event dedup, behavior update, invalid request; временный гость удалён.
Живой /search smart по УСН прошёл: реальные карточки, assistant_status=disabled.
Cloud ключ отсутствует, настоящий LLM-вызов не проверялся.

compileall, node --check, docker compose config --quiet, git diff --check, ссылки
README/docs прошли. Compileall выполнен с PYTHONPYCACHEPREFIX в /private/tmp:
системная настройка иначе пыталась писать кеш в закрытый Library/Caches.

Снимок исходников reco/tests/scripts/specs (*.py/js/html/css/json/md) и
compose.yaml/requirements.txt/env.example SHA256:

## Ограничения и следующий шаг

Docker Engine здесь недоступен: build/run и Windows не проверены. Mac CPU-проверка
не заменяет Windows-тест. Для жюри нужна проверка Docker Desktop Linux/WSL2 на
Windows и времени первой индексации. Cloud LLM требует ключа владельца; качество
уточнений с живым провайдером остаётся проверить. Публикация/PR/ревью A/B/верификатор
текущей версии не выполнялись и потребуются перед порученным push.

Последний вопрос владельца о кнопке входа: UI пока создаёт только анонимного гостя;
evaluation/profiles.json используется для оценки, не для входа. Переключателя
синтетических профилей нет; предложен отдельный явно обозначенный демо-переключатель.
Реальная авторизация в рамках текущего изменения не реализована.
