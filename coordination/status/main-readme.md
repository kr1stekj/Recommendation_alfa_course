профили/TTL, LLM, API/CLI, файлы индекса, проверки и известные ограничения.

docker compose config --quiet. Для полной suite используется отдельная alfa_test.

без пропусков на отдельной alfa_test, блокеров нет. Отчёты —
coordination/reviews/2026-11-14-main-readme-{a,b,verifier}.md; проверены CLI/help,
14 bash-блоков, 22 относительные ссылки, Compose config и совместимость с main.
Целевая main eb1b63b, исходная fix/nan-handling 0d288cd. Исполняемый код этапом
не менялся, финальный дополнительный commit сохраняет только отчёты и этот статус.

от агента. Docker runtime, живая Ollama и CI не выдаются за выполненные проверки.

не сохраняются в репозитории и не выводятся. main не защищена, обход защиты не нужен.
