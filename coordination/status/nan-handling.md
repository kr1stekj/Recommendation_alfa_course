# Обработка пропусков, 14 ноября 2026

Задача: по прямому поручению пользователя заменять NaN безопасными пропусками,
чтобы текстовая очистка, разбор цен и косинусные расчёты не падали на них.
Ветка: fix/nan-handling, база ac4fe45. Существующие незакоммиченные изменения
документации сохранены; чужие изменения не коммитились и не перезаписывались.

Область: reco/missing.py, reco/data.py, reco/embeddings.py, reco/index.py,
tests/test_missing.py, tests/test_index.py и дополнение правил очистки в README.
Контракт API и схема PostgreSQL не меняются. Настоящий NULL у Courses.Cost
по-прежнему означает бесплатный курс; NaN или испорченная цена означает unknown.
NaN в тексте — пустая строка; обязательные пустые поля исключают карточку.
Нечисловые координаты не распространяются по косинусным расчётам; сохранённый
индекс с NaN/Infinity отвергается даже при корректных контрольных суммах.
