# Сравнение ruBERT и BGE-M3 — 15 ноября 2026

Проверен локальный снимок ветки `feat/cloud-llm-api` на базе `2a02e8e`.
Использованы настоящие карточки и история из предоставленного PostgreSQL backup.
Обучение и подбор весов ранжирования не проводились, облачная LLM выключена.
Это исторический прогон до hybrid-v2: приведённые метрики не оценивают новые веса
и fallback из [ranking-components.md](../specs/ranking-components.md).

## Данные и методика

Обе модели получили одинаковые исходные проекции карточек и истории; SHA256
проекций совпали. Всего 1126 индексируемых материалов, из них 1115 доступны
для выдачи; 10032 строки производной истории. Старое поколение сохранено.
Результаты содержат только метрики и ID материалов, без выгрузки истории пользователей.

Для качества использованы пять известных синтетических сценариев из
[profiles.json](../evaluation/profiles.json) с неполной черновой разметкой автора.
Неоценённые материалы считаются нерелевантными. Это повторная проверка на известном
наборе, не независимый тест, экспертная оценка или доказательство роста конверсии.

Модели запускались отдельными процессами. CPU Mac arm64, 8 ГиБ RAM, два потока
PyTorch 2.6, transformers 4.48.3, float32. После прогрева каждый из пяти коротких
запросов кодировался трижды: 15 замеров. Длина запросов BGE — 10–17 токенов,
ruBERT — 8–14. Это замер encoder без HTTP и LLM, без нагрузки и длинных документов.

| Encoder / метод | Precision@5 | NDCG@5 |
|---|---:|---:|
| Темы + популярность (оба) | 0.12 | 0.0810 |
| ruBERT / косинус | 0.24 | 0.3668 |
| ruBERT / гибрид | 0.36 | 0.4651 |
| BGE-M3 / косинус | 0.36 | 0.5789 |
| BGE-M3 / гибрид | 0.44 | 0.5458 |

| Измерение CPU | ruBERT | BGE-M3 |
|---|---:|---:|
| Размерность | 312 | 1024 |
| Warm p50, мс | 1.51 | 111.42 |
| Warm p95, мс | 2.94 | 2010.30 |
| RSS процесса в конце проверки, МиБ | 397.09 | 1273.83 |

Небольшая выборка задержек чувствительна к состоянию машины. RSS не является пиком
памяти при загрузке или сборке. По этим данным нельзя обещать задержки для Windows,
512/8192 токенов, другого CPU или большого RPS. Косинус BGE здесь показал NDCG выше
гибрида; веса по этой же выборке не подстраивались, алгоритм по умолчанию не менялся.

## Реальная сборка и запуск

Официальная [BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3), revision
`5617a9f61b028005a4858fdac845db406aefb181`, CLS pooling, L2, max_length=512,
batch_size=4. Размер файла весов — 2271145830 байт; SHA256 совпал с официальными
метаданными LFS: `b5e0ce3470abf5ef3831aa1bd5553b486803e83251590ab7ff35a117cf6aad38`.
Сторонние Docker-образы не использованы.

На этом Mac сборка с MPS заняла 2541.299 с (около 42 минут), без времени скачивания
2,27 ГБ весов. Полная CPU-сборка для сравнения скорости не запускалась. Все координаты
1126×1024 конечны, длины векторов 0.99999994–1.0. У двух контрольных запросов
cosine между CPU и MPS результатами — 1.0; это ограниченная проверка согласованности.

Новый API запущен на **CPU**, `/health` подтверждает BAAI/bge-m3 и 1024 координаты.
Умный поиск по запросу об УСН вернул реальные материалы каталога. Внешняя LLM без
ключа отключена; этот сценарий не выдаётся за проверку облачной модели.

Для Windows предусмотрен Docker Desktop с Linux containers/WSL 2, CPU и named volumes
для модели/индекса. Команды PowerShell — в [README](../README.md). Compose config
проверен; фактические Docker build/run и Windows-запуск в этой среде не выполнялись.
Параметр MPS необязателен и не сохраняется как требование к устройству runtime.

## Воспроизведение

Сначала соберите оба индекса из одного backup в разные каталоги и одну служебную
PostgreSQL, сохранив старое поколение. Настройте DATABASE_URL, установите зависимости.
Каждый замер запускайте отдельным процессом:

```bash
python scripts/benchmark_embeddings.py --artifacts artifacts-rubert --device cpu --output artifacts-rubert/benchmark.json
python scripts/benchmark_embeddings.py --artifacts artifacts --device cpu --output artifacts/benchmark-bge.json
```

Скрипт сохраняет настройки, устройство параметров модели, условия, хэши проекций,
метрики и ограничения. Артефакты, веса, backup и история не коммитятся. Для следующей
оценки нужна расширенная независимая разметка, не повторный подбор по пяти сценариям.
