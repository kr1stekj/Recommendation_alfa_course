# Презентация «Майёвтики», трек 1

PDF для сдачи и редактируемый PPTX, 15 слайдов: 12 основных и 3 приложения. Созданы 16 ноября 2026 по
предоставленным требованиям и исходному коду. Версия сдачи: main после слияния пакета feat/submission-package,
основа main d816199, алгоритм свежести b632f83 (ревью847118c).
Состав: Маньшин Алексей, Аксенов Степан, Дроздков Игорь, Андреев Максим.

На первом слайде - репозиторий и порядок проверки. Снимки интерфейса используют
реальный каталог и синтетические события; вопрос демонстрационный, без нового
вызова LLM. Старые метрики пяти профилей явно предварительные, не оценка текущей
версии. Windows runtime и рост конверсии не заявляются подтверждёнными.

Происхождение: авторская презентация, созданная для команды через Artifact Tool;
PDF собран из проверенных рендеров с текстовым слоем и кликабельной ссылкой.
Контрольные суммы файлов: checksums.json. Рабочих ключей/реквизитов здесь нет.
ZIP с локальными настройками пользователя в репозиторий не включается.

Добавлены сквозной сценарий с фактической локальной выдачей после подписанного
ответа и сравнение ruBERT/BGE-M3. Вопрос подготовлен, внешняя LLM не вызывалась.
