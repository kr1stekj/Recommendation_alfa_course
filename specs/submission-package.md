# Настройки и пакет сдачи

Поручение владельца: hero показывает 67; прокси настраивается через локальный
.env; API-ключ и прокси собраны в текстовый файл вместе с презентацией в архив.

Compose читает RECO_PROXY_URL (пусто по умолчанию) и передаёт HTTP(S)_PROXY в
обоих регистрах только recommender. NO_PROXY/no_proxy исключают loopback,
postgres и host.docker.internal. Host HTTPS_PROXY не подменяет эту настройку.
Секреты отсутствуют в Compose, шаблоне и презентации; LLM_API_KEY как раньше
читается из .env. Существующие .env без прокси продолжают работать напрямую.
Изменение настроек требует пересоздания контейнера, не пересчёта embeddings.

Текстовый файл и ZIP с реальными настройками создаются только локально в
private/ и output/, исключённых из Git. Docker использует whitelist build
context, обе папки туда не входят. В Git публикуется только презентация без
секретов, шаблон и код/документация. Старую историю Git с прежними реквизитами
не переписываем; рабочие секреты из старых коммитов владелец может заменить.

Приёмка: 67 без поворота; Compose с заданным/пустым прокси, обход localhost и
отсутствие proxy у PostgreSQL; ключ и реквизиты только в локальных файлах;
архив содержит PDF, PPTX и текст настроек; PDF имеет ссылку на репозиторий.
Живые LLM-запросы и повторная векторизация для проверок не используются.
