# Персональная стартовая страница

При пустом task без answers/clarifications /search показывает feed независимо от
переключателя normal/smart. Непустой normal остаётся лексическим, smart — прежним.
По умолчанию 10 карточек: 8 по персональному ранжированию, 1 популярная,
1 материал для знакомства с другой темой. Для малого каталога доля дополнительных
слотов уменьшается: популярный при n>=5, случайный при n>=10. Без данных
популярности первый дополнительный слот также маркируется как знакомство.
Без истории основа
стартовая, а не выдуманные интересы. LLM не вызывается даже при use_llm=true.

Отбор дополнительных карточек идёт из того же пула eligible, с прежними
исключениями complete/dislike. Дубликаты запрещены. Популярность — действующая
нормализованная история; случайный слот — hash(profile,dataset,UTC day,item),
по возможности новая тема и материал без взаимодействий. Обновление страницы
с тем же профилем не обнуляет клики и не перетасовывает случайный слот.

Персональная часть чередует до четырёх тем положительной истории. Все метки
каталога равноправны: порядок не означает главную тему. Материал, подходящий
нескольким темам, занимает только один слот. Вес и свежесть тем задают количество мест: сначала по одному доступным темам,
затем взвешенное распределение оставшихся слотов. Подробная формула и правила
затухания - `interest-recency.md`. При равных весах/свежести двух непересекающихся
тем получается 4/4, при более свежем интересе ему достаётся больше мест.
Нехватка одной темы заполняется другими; отрицательные темы не создают квот.
У новичка используются центроиды каталога без загрузки encoder.

В recommend добавляется discovery:bool=false, допускается только без task и
без LLM. API search возвращает feed_mode=true, у карточек feed_source.
UI показывает «Подборка для вас» и источники вместо «Обычный поиск» для feed.
На карточке видны все метки каталога, включая вторую «Управление командой»,
когда первой записана «Налоги и законы». Исходная категоризация не переписывается.
ID гостя по-прежнему в localStorage, агрегат в PostgreSQL, TTL без изменений.
Новых схем/моделей/зависимостей и пересчёта индекса нет.

Приёмка: клики → новый экземпляр SmartSearch → персональная пустая выдача в обоих
режимах; 8/1/1, нет дублей/недоступных/completed/disliked, стабильный random,
холодный старт/малый каталог, normal с текстом не читает историю, LLM запрещена.
